GPA Calculator Script
A simple Python program that takes a numerical mark as input and determines the corresponding Grade Point Average (GPA) based on a predefined scale.

How It Works
The script uses conditional logic (if-elif-else) to categorize a user's score. It follows these steps:

Prompts the user to enter their marks.

Converts the input into an integer.

Checks the integer against various thresholds (90, 80, 70, 60).

Prints the resulting GPA to the console.

Grading Scale
Marks Range	GPA
90 and above	4.0
80 - 89	3.0
70 - 79	2.0
60 - 69	1.0
Below 60	0.0
Requirements
Python 3.x installed on your system.

Usage
Clone or copy the script to a file named gpa_calculator.py.

Open your terminal or command prompt.

Run the script using the following command:

Bash
python gpa_calculator.py
Enter your marks when prompted and press Enter.
